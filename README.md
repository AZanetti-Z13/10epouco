# 10 e Pouco · Mensalidades

Site de consulta das mensalidades do 10 e Pouco F.C. (Futebol & Cerveja).

- Os dados vêm direto da planilha "Contabilidade 10 e Pouco F.C." no Google Planilhas.
- Cada aba visível da planilha é um jogador (a aba CAIXA é ignorada; aba oculta não aparece).
- Configurações (Pix, links, valor da mensalidade): `dados.js`.
- Fotos dos jogadores: pasta `fotos/` (veja `fotos/LEIA-ME.txt`).
- Para abrir no computador: `abrir-site.bat`.
